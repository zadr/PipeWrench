### Test pattern

For retain cycles, the standard test is:

```swift
func test_<thing>_doesNotLeak() {
    var sut: <Type>? = // construct the cycle
    weak var weakSUT = sut
    sut = nil
    XCTAssertNil(weakSUT, "retained — likely a retain cycle")
}
```

For heap growth, assert that a collection size stays bounded. For autorelease bloat, measure pool size. Place the test in an existing test file or a new file in the same Tests/ directory.

### Fix rules

1. Implement exactly what `fix_description` says.
2. Follow `nil_handling` exactly. Never silently funnel nil into a retry/buffer path.
3. Make ONLY the changes specified. Do not refactor unrelated code.
4. Be succinct. No essays. Commit messages: one summary line, short body. Code comments: one line. Never reference memgraph IDs, UUIDs, or pipeline identifiers.

When done, output NOTHING except the word DONE.
